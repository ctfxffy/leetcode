# 49. 字母异位词分组

**难度：中等**

## 题目描述

给你一个字符串数组，请你将字母异位词组合在一起。可以按任意顺序返回结果列表。

## 示例

### 示例 1

**输入：**

```text
strs = ["eat", "tea", "tan", "ate", "nat", "bat"]
```

**输出：**

```text
[["bat"],["nat","tan"],["ate","eat","tea"]]
```

**解释：**

- 在 `strs` 中没有字符串可以通过重新排列来形成 `"bat"`
- 字符串 `"nat"` 和 `"tan"` 是字母异位词，因为它们可以重新排列形成彼此
- 字符串 `"ate"`、`"eat"` 和 `"tea"` 是字母异位词，因为它们可以重新排列形成彼此

### 示例 2

**输入：**

```text
strs = [""]
```

**输出：**

```text
[[""]]
```

### 示例 3

**输入：**

```text
strs = ["a"]
```

**输出：**

```text
[["a"]]
```

## 提示

- `1 <= strs.length <= 10^4`
- `0 <= strs[i].length <= 100`
- `strs[i]` 仅包含小写字母
