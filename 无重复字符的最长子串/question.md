# 3. 无重复字符的最长子串

**难度：中等**

## 题目描述

给定一个字符串 `s`，请你找出其中不含有重复字符的最长子串的长度。

## 示例

### 示例 1

**输入：**

```text
s = "abcabcbb"
```

**输出：**

```text
3
```

**解释：**

因为无重复字符的最长子串是 `"abc"`，所以其长度为 `3`。注意 `"bca"` 和 `"cab"` 也是正确答案。

### 示例 2

**输入：**

```text
s = "bbbbb"
```

**输出：**

```text
1
```

**解释：**

因为无重复字符的最长子串是 `"b"`，所以其长度为 `1`。

### 示例 3

**输入：**

```text
s = "pwwkew"
```

**输出：**

```text
3
```

**解释：**

因为无重复字符的最长子串是 `"wke"`，所以其长度为 `3`。

请注意，你的答案必须是子串的长度，`"pwke"` 是一个子序列，不是子串。

## 提示

- `0 <= s.length <= 10^5`
- `s` 由英文字母、数字、符号和空格组成
