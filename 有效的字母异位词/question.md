# 242. 有效的字母异位词

**难度：简单**

## 题目描述

给定两个字符串 `s` 和 `t`，编写一个函数来判断 `t` 是否是 `s` 的字母异位词。

## 示例

### 示例 1

**输入：**

```text
s = "anagram", t = "nagaram"
```

**输出：**

```text
true
```

### 示例 2

**输入：**

```text
s = "rat", t = "car"
```

**输出：**

```text
false
```

## 提示

- `1 <= s.length, t.length <= 5 * 10^4`
- `s` 和 `t` 仅包含小写字母
